# Report fonts

Embedded in the PDF usage reports (`src/services/report/pdf.rs`): Geist,
the dashboard's own family, regular and semibold, and Geist Mono for the
wordmark and identifiers.

- Source: <https://github.com/vercel/geist-font> release v1.7.2 (`Geist/ttf/`, `GeistMono/ttf/`).
- Licence: SIL Open Font License 1.1, see `Geist-OFL.txt`.
